User guide

  1. Import data: load CSV or Excel; select worksheet for Excel.
  2. Data management: confirm column types, apply them, and filter if needed.
  3. Data quality: inspect missing values, duplicates, invalid values, and IQR outliers.
  4. Descriptive statistics: select one variable and calculate its summary.
  5. EDA: choose variables and create charts.
  6. Relationships: calculate correlations or fit regression models.
  7. Comparative tests: run t-tests, ANOVA, or rank-based tests.
  8. Inference: run a one-sample t-test, confidence interval, and normality assessment.
  9. Time series: select date and value fields, set the maximum ACF lag, then analyze.
  10. Report: build and print the report.

Implemented features

  • CSV and Excel import; worksheet selection; preview; type detection and manual typing.
  • Consistent missing-value detection for empty, whitespace-only, NA, N/A, null, undefined, and NaN values.
  • Missing values, duplicate rows/columns, invalid values, IQR outliers, filtering, and non-destructive cleaning.
  • Full numerical and categorical descriptive statistics.
  • Histogram, box, scatter, line, bar, pie, frequency, and correlation heatmap.
  • Pairwise-aligned Pearson, Spearman, and Kendall tau-b correlations; lagged correlation; simple, multiple, and polynomial OLS regression.
  • Independent/paired t-tests, one-way ANOVA, Mann–Whitney U, Wilcoxon signed-rank, and Kruskal–Wallis tests with tie corrections where applicable.
  • One-sample t-test, selectable confidence interval, Shapiro–Francia normality assessment.
  • Time-series plot, moving average, rolling SD, user-controlled ACF maximum lag, lag analysis, and resampling.
  • CSV/Excel export, chart PNG export, printable report, and PDF printing.

Limitations

  • Shapiro–Wilk is not implemented; Shapiro–Francia is used instead.
  • Mann–Whitney, Wilcoxon, and Kruskal–Wallis use large-sample normal/chi-square approximations, with tie corrections; exact small-sample distributions are not used.
  • No Bayesian methods, mixed models, GLMs, survival analysis, or multiple-comparison correction.
  • Correlation does not establish causation; small samples have low power.
  • Regression assumes independent observations, approximate linearity, constant residual variance, and no severe influential outliers.
